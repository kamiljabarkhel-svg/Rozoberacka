# Rozoberačka

Portál na použité autodiely na Slovensku. Kupujúci hľadajú diel podľa svojho auta (značka, model, motorizácia), predajcovia (vrakoviská) pridávajú inzeráty.

| Súbor | Čo to je |
| --- | --- |
| `prototyp.html` | Funkčné demo v prehliadači (dáta len v prehliadači) |
| `CLAUDE.md` | Zadanie projektu pre Claude Code |
| `DENNIK.md` | Denník stavby a otvorené úlohy |
| `.claude/agents/dirigent.md` | Agent Dirigent, ktorý riadi stavbu |
| `supabase/` | Databáza pre Supabase, otestovaná na PostgreSQL 16 |

Začiatok práce v Claude Code: „Použi agenta dirigent.“
